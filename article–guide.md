# Руководство по разметке статей (Markdown & HTML)

В этом проекте статьи хранятся в папке `_articles/` в виде файлов `.md`. Они поддерживают как стандартный синтаксис Markdown, так и HTML-теги для создания сложных журнальных и газетных макетов.

---

## 1. Метаданные статьи (Front Matter)
Каждая статья должна начинаться с блока метаданных между тройными дефисами `---`:

```yaml
---
slug: "history"                            # Уникальный ID статьи (латиница)
title: "Історичний екскурс"                 # Заголовок на странице статьи (можно использовать <br>)
plainTitle: "Історичний екскурс"            # Чистый заголовок для хлебных крошек и вкладки браузера
image: "img/newspaper_grid_1777876473624.png" # Главное изображение статьи (обложка справа)
chapterId: "chapter-1"                     # ID главы, к которой относится статья
---
```

## 2. Текстовые теги и автоматическое форматирование

Система автоматически применяет изысканные газетные стили к тексту в блоке `.article-content`:

| Тег / Конструкция | Описание и применение | Автоматическое поведение (CSS) |
| :--- | :--- | :--- |
| `<h2>...</h2>` | **Подзаголовок второго уровня**. Разделяет крупные логические блоки. | Шрифт с засечками (serif), полужирный. Добавляет красивый отступ сверху (`2.5rem`) и снизу (`1rem`). |
| `<h3>...</h3>` | **Подзаголовок третьего уровня** для мелких подразделов. | Чуть меньший размер, также имеет отступы. |
| `<p>...</p>` | **Абзац текста**. Основное текстовое наполнение статьи. | Выравнивание по ширине (`text-align: justify`), переносы слов (`hyphens: auto`). |
| **Буквица (Drop Cap)** | Автоматически применяется к первой букве **самого первого** абзаца статьи. | Первая буква увеличивается до `4.5rem`, приобретает красивый шрифт и обтекание текстом. |
| **Красная строка** | Автоматический абзацный отступ (`text-indent: 1.5rem`). | Применяется ко всем `<p>`, **кроме**: первого абзаца статьи, абзаца сразу после `<h2>`/`<h3>` и абзаца сразу после обтекаемой слева картинки. |
| `<br>` | Перенос строки внутри абзаца или заголовка. | Переносит текст на новую строку. |
| `•` или `<ul>`/`<li>` | Списки. | Можно оформлять списки вручную через `<br>• элемент` или использовать стандартные теги списков. |
| **Цитата (Quote)** | Используйте тег `<blockquote>` с классом `article-quote` для выделения мыслей и цитат. | Изысканный serif шрифт Cormorant Infant, крупная двойная кавычка сверху, увеличенный кегль, выравнивание по левому краю без красной строки. Поддерживает `<cite>` для указания автора. |

### Пример использования цитаты (Quote):
```html
<blockquote class="article-quote">
  Vivre were thoughtful, professional, and <em>genuinely understood</em> who we are as a brand.
  <cite class="quote-author">Автор цитаты</cite>
</blockquote>
```

## 3. Работа с изображениями и SVG

Изображения можно вставлять как через Markdown (`![](путь)`), так и через HTML (`<img src="...">`).

### Автоматическое выравнивание изображений
Шаблонный движок в `cms-client.js` анализирует пропорции картинок (соотношение сторон) и автоматически раскладывает их по макету:
* **Широкие изображения (соотношение ≥ 1.4)**:
  Получают класс `.img-layout-full-width` — растягиваются на всю ширину текстового блока.
* **Вертикальные изображения (соотношение ≤ 0.8)**:
  Получают классы `.img-layout-float-right` и `.img-portrait` — прижимаются вправо и красиво обтекаются текстом.
* **Квадратные/обычные изображения (0.8 < соотношение < 1.4)**:
  Поочередно выравниваются то влево (`.img-layout-offset-left`), то вправо (`.img-layout-float-right`) для создания динамичного ритма чтения.

### Работа с интерактивными SVG-схемами
Для сложных векторных иллюстраций используйте тег `<svg>` с классом `article-inline-svg`:
```html
<svg class="article-inline-svg" viewBox="0 0 500 300">
  <!-- Внутри могут быть любые SVG элементы: rect, circle, path, text и т.д. -->
</svg>
```
* **Очистка фона:** Система автоматически найдет все элементы внутри SVG с заливкой белого цвета (`#ffffff`, `white`, `rgb(255,255,255)`) и сделает их прозрачными (`transparent`), чтобы SVG гармонично смотрелся на любом фоне.
* **Анимация появления:** Все дочерние элементы SVG (кроме мета-тегов `<defs>`, `<style>`) автоматически получают анимационные классы и плавно прорисовываются при прокрутке страницы до них.

## 4. Сложные многоколоночные сетки (Layout Grid)

Если вам нужно разместить текст и изображения в несколько колонок (например, сделать асимметричный макет или сайдбар), используйте специальную сетку:

```html
<div class="layout-grid layout-half">
  <!-- Левая колонка -->
  <div class="grid-col">
    <p>Текст в левой колонке...</p>
  </div>
  
  <!-- Правая колонка -->
  <div class="grid-col">
    <img src="img/example.jpg" alt="Описание">
  </div>
</div>
```

### Доступные классы пропорций сеток (добавляются к `layout-grid`):
* `layout-half` — две равные колонки (`1fr 1fr`).
* `layout-asymmetric` — асимметричный макет, левая колонка уже (`2fr 3fr`).
* `layout-asymmetric-reverse` — асимметричный макет, правая колонка уже (`3fr 2fr`).
* `layout-sidebar` — левая колонка очень узкая (сайдбар), правая широкая (`1fr 3fr`).
* `layout-triptych` — пропорции `2fr 1fr`.
* `layout-triptych-reverse` — пропорции `1fr 2fr`.

*Примечание: на мобильных устройствах (ширина экрана ≤ 768px) все эти сетки автоматически перестраиваются в одну вертикальную колонку для удобства чтения.*
